# S.U.N. Studio

The website of S.U.N. Studio (Solar Utility Nexus), a free Windows program that turns solar captures into aligned, graded timelapses: https://sunstudioapp.com

The program itself is a download under [Releases](../../releases).

The site is plain HTML, CSS and JavaScript with no build step. To preview it locally: `python serve_preview.py`, then open http://127.0.0.1:8737
